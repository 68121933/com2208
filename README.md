# งานใหม่01 ตอบคำถาม 3 ข้อ
1.เทคโนโลยี
ตอบ เทคโนโลยี คือ สิ่งที่มนุษย์คิดค้นหรือพัฒนาขึ้นเพื่อช่วยให้ชีวิตประจำวันง่ายขึ้น และช่วยแก้ปัญหาต่าง ๆ เช่น โทรศัพท์มือถือช่วยให้ติดต่อกันได้สะดวก เครื่องซักผ้าช่วยประหยัดเวลา และคอมพิวเตอร์ช่วยในการเรียนและทำงาน ดังนั้น เทคโนโลยีจึงมีความสำคัญต่อการดำเนินชีวิตของมนุษย์ แต่เราควรเลือกใช้ให้เหมาะสมและเกิดประโยชน์มากที่สุด

2.นวัตกรรม
ตอบ นวัตกรรม คือ การคิดสิ่งใหม่ขึ้นมาหรือพัฒนาสิ่งเดิมให้ดีขึ้น เพื่อให้เกิดประโยชน์และช่วยแก้ปัญหาในชีวิตประจำวัน เช่น การจ่ายเงินด้วย QR Code การนำขยะมารีไซเคิล และการเรียนออนไลน์ นวัตกรรมจึงไม่จำเป็นต้องเป็นสิ่งประดิษฐ์ที่ล้ำสมัยเสมอไป แต่ต้องเป็นแนวคิดหรือวิธีการที่นำไปใช้แล้วช่วยให้เกิดการเปลี่ยนแปลงหรือผลลัพธ์ที่ดีขึ้น

3.Design Thinking
ตอบ Design Thinking หรือการคิดเชิงออกแบบ คือ วิธีคิดแก้ปัญหาอย่างเป็นขั้นตอน โดยเริ่มจากการเข้าใจปัญหาของผู้อื่น กำหนดปัญหาให้ชัดเจน ระดมความคิด สร้างต้นแบบ และทดลองใช้เพื่อปรับปรุงให้ดีขึ้น วิธีนี้ช่วยให้เราแก้ปัญหาได้ตรงจุดและสร้างสรรค์สิ่งใหม่ ๆ ที่ตอบโจทย์ความต้องการของผู้คนได้จริง สูตร เข้าใจปัญหา → กำหนดปัญหา → คิดหาวิธีแก้ → สร้างต้นแบบ → ทดลองและปรับปรุง
